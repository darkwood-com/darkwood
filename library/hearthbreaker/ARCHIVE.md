# Archived project

This directory preserves the last reviewed snapshot of Hearthbreaker from source
commit `de418ed301f770596f6121158348b54ee9efa39f`.

The original Git history was not imported because it contains historical secret
detections and obsolete PuPHPet provisioning material. The tracked `.env` file
was replaced by a placeholder-only `.env.example` in this snapshot.

The project is retained for source-history and reference purposes. Its historical
Symfony runtime has not been modernized or executed as part of this import.
