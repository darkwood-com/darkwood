## What this reveals about Hellcats

The original game explicitly separates a player's request to end a mission from confirmation of that request.

Two related resources now establish the complete alert definition:

- `ALRT` 259: provides the alert window and links to DITL 259.
- `DITL` 259: provides the confirmation message and the two available actions.

The warning also gives an important original game rule: manually ending the current mission is presented as forfeiting points. Whether every score component is discarded requires code verification.
