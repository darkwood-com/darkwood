## Decoded `ALRT` resource — ID 261

Resource name: `Not on floppy` Identified purpose: Installation warning displayed when Hellcats Over the Pacific is launched from its original floppy disk rather than a hard disk.

This classic Macintosh `ALRT` (Alert Template) resource defines the window geometry, the associated dialog item list and the alert-stage settings.

## What this reveals about Hellcats

The game has a dedicated alert for rejecting execution from the original floppy disk.

Together, the two resources establish a complete interface definition:

`ALRT 261 → DITL 261 → Installation warning + Quit`

The supplied data proves that this is a distinct alert template, not merely a different error message inserted into the generic 322 × 108 alert.

For your strict Godot port, preserve the original 361 × 108 pixel rectangle, position `(40, 40)`, warning text and `Quit` button.
