## What this reveals about Hellcats

The `Error` alert is structurally different from the more specialized scenery-loading warning (`ALRT` 256).

Where the scenery alert embeds a complete sentence with a single filename placeholder, `ALRT` 258 delegates its message to the generic template:

`^1 ^0.`

This makes it a potentially reusable error-reporting mechanism.

For your strict Godot port, preserve the distinction between these alert types. The resource provides the exact window geometry and message template, but not the runtime errors or substitution values.
