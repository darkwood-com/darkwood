## What this reveals about Hellcats

This resource confirms that the original game uses the Macintosh Alert Manager to display its settings-save confirmation, rather than a custom-drawn dialog.

For your strict Godot port, the original relationship can be preserved as:

`ALRT 257 → DITL 257 → Save / Cancel / Don't Save`

The essential implementation details are the 322 × 108 pixel alert, its exact screen position, the four controls from the linked DITL, and the original confirmation wording.

The next useful investigation is the original CODE routine invoking alert `257`, which should establish exactly when the save prompt appears and how each button affects the settings file and application shutdown.
