## What this reveals about Hellcats

The original game requests approximately 1.5 MiB of RAM for its application partition, but declares that it can launch with as little as 800 KiB.

This is particularly interesting for your strict port: it establishes the memory budget declared by the Macintosh application, although it does not reveal how that memory was distributed between the simulation, graphics, aircraft models, and other resources.

These values are worth keeping in your historical documentation. You don't need to reproduce the same memory limits in Godot, but they help explain the constraints under which the original engine operated.
