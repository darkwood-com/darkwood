## What this reveals about Hellcats

The `Copy Protection` dialog is a relatively large window measuring 470 × 287 pixels, positioned at `(20, 34)`.

One notable difference from the previously decoded dialogs is that `visible = true`. All the other `DLOG` resources examined so far were initially marked invisible.

This resource is also related to the previously decoded `TEXT` ID `1000`, which contains the game's original copy-protection instructions involving an unlock code and a word from the manual.

However, the `DLOG` alone does not establish how that text is displayed or how the unlock code is verified.

For your strict Godot port, the relevant resources are:

- `DLOG` 1000 — window geometry and configuration.
- `DITL` 1000 — dialog controls and their positions.
- `TEXT` 1000 — copy-protection instructions.
- `styl` 1000 — text formatting.
