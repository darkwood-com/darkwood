## Decoded `CNTL` resource — ID 128

Resource name: Empty Identified purpose: Vertical scrollbar control in Hellcats Over the Pacific.

This classic Macintosh `CNTL` (Control Template) resource defines a 16 × 70 pixel scrollbar, using the standard Macintosh Control Manager scrollbar procedure.

Unlike `DLOG`, `DITL`, and `ALRT` resources, a `CNTL` resource describes an individual control that can be instantiated by the application.

### Important: procedure ID `0x0010`

The hexadecimal value `0010` is decimal 16, corresponding to the standard Macintosh `scrollBarProc`.

It is not an application-defined control type indicated by the resource.

The standard Control Manager procedures include:

| Procedure ID | Standard control |
| ------------ | ---------------- |
| `0x0000`     | Push button      |
| `0x0001`     | Checkbox         |
| `0x0002`     | Radio button     |
| `0x0010`     | Scrollbar        |

This identifies the control as a scrollbar, rather than a generic 16-pixel-wide panel.
