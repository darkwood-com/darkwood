## What this reveals about Hellcats

Three particularly interesting features emerge for strict port.

- Triple Time: The original game exposed a command suggesting accelerated simulation time. Its precise multiplier and effect on simulation versus rendering need to be recovered from the code rather than inferred solely from the label.
- Cockpit Views Pan: This confirms the presence of a cockpit view-related option. The precise camera behavior remains to be investigated.
- Display height modes: `Full Screen`, `3/4 Height` and `1/2 Height` suggest the original game supported different viewport sizes, likely relevant to performance on older Macintosh hardware.
