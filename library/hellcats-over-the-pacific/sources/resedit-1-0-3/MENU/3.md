## What this reveals about Hellcats

The Edit menu follows the standard classic Macintosh conventions. However, unlike the File menu (`MENU` ID 2), its initial enable flags are all zero.

This is relevant because the menu may have been included primarily for standard Macintosh compatibility, with editing operations made available only in particular windows or dialogs.

For strict Godot port, preserve the original menu labels and keyboard shortcuts, but don't assume that Undo, Cut, Copy and Paste are always functional.
