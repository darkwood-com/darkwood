## Decoded `DITL` resource — ID 1000

Associated dialog: `Copy Protection` (`DLOG` ID 1000)

This classic Macintosh `DITL` (Dialog Item List) resource defines the 11 interface elements of the original Hellcats Over the Pacific copy-protection dialog.

It contains the manual-verification instructions, two editable text fields, a serial-number display, `OK` and `Quit` buttons, and a reference to `PICT` ID 1000.

Unlike `DITL` ID 135, which contains similar copy-protection instructions, this resource embeds a picture rather than displaying all the unlock-code instructions as static text.

## Original dialog content

The main instructions are:

> Please refer to Section 3, "Principles of Flight", of your "Pilot's Handbook for Navy Model F6F  Airplane"

> Turn to page 3-^0, and look at line ^1 of the 1st column. Count ^2 word(s) from the left.  Enter the word below:

The dialog also contains:

> Serial #:

> If you wish to never see this dialog again, follow these steps:

The serial-number value is represented by the literal string `^3`.

The markers `^0`, `^1`, `^2` and `^3` are preserved exactly. Their use as runtime substitution placeholders is strongly suggested by the surrounding text, but their replacement logic must be verified in the original executable.

## What this reveals about Hellcats

There are three important findings for your strict Godot port.

1\. The original interface has two distinct input fields. Item 3 sits immediately beneath the handbook word-selection instructions. Item 4 is located at the bottom of the dialog. Given the surrounding copy-protection instructions, the latter is plausibly for an unlock code, although this role needs confirmation from the original application code.

2\. `PICT` ID 1000 is a significant part of the dialog. Its rectangle occupies 438 × 91 pixels, beneath the introductory instructions about avoiding future copy-protection prompts. Its actual contents cannot be recovered from the `DITL` alone.

3\. The manual challenge is parameterized. The encoded strings reference page `3-^0`, line `^1`, word `^2`, and serial `^3`. The resource reveals the presentation format, not how the numbers are generated or verified.

For a faithful recreation, retain the original strings, carriage returns, double spaces, field positions and `PICT` reference. The most useful next extraction is `PICT` ID 1000, followed by inspection of the original CODE routines that populate the challenge and process the two input fields.
