## What this reveals about Hellcats

This resource is particularly valuable for your strict Godot port because it establishes the original map UI structure, rather than only a generic dialog window.

The main map uses a 253 × 253 pixel square, while the adjacent panel displays navigation information, a legend, and zoom controls. The three initially empty static-text fields likely display live values such as heading, range and scale, although their assignments need to be confirmed through code analysis.

The legend also gives directly recoverable symbology for the game's navigation map. You can reproduce the five symbols exactly without inventing new map markers.
