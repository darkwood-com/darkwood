### What this reveals about Hellcats

The two About dialogs share their entire interface layout. Only the background picture reference changes.

This strongly suggests that the game provides two variants of the same About screen:

- `PICT` 128: standard About Hellcats artwork.
- `PICT` 129: alternative artwork associated with the 1-bit About dialog.

The actual color depth of either picture still requires examining its resource data.

For your strict Godot port, this means you can reproduce both dialogs using one shared layout, with a different picture selected according to the original game's rendering conditions.
