# Contributing

## Commit messages

Use the [Gitmoji](https://gitmoji.dev/) convention for every commit:

```text
<gitmoji> <imperative description>
```

Use the actual Unicode emoji, choose the emoji that best describes the change, and keep the English description concise and imperative.

Examples:

```text
✨ Add provider account discovery
🐛 Handle an unavailable SQLite database
📝 Update installation instructions
```

Do not add Conventional Commit prefixes such as `feat:`, `fix:`, or `chore:`.
