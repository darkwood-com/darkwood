Un parcours, une candidature

MARIO ORCHESTRATION
  1. Intention
  2. Outil MCP
  3. Agent Symfony AI
  4. OpenAI
  5. JSON validé

La card existante Mario Orchestration est retenue pour une génération structurée de niveau de plateforme. Le serveur stdio utilise Mcp\Server\Server et expose generate_original_level. L’agent level_generator appelle réellement le fournisseur ; le résultat est décodé et contrôlé avant d’être retourné.

Socle testé localement : Symfony AI 1.0.0-BETA1, SDK mcp/sdk 0.10.0, Symfony 8.1.11, PHP 8.5. Licence MIT. Flow et Navi restent des dépendances du projet ; le parcours retenu ne prétend pas démontrer leur orchestration multi-agent.

Limites connues

PORTÉE DES PREUVES

Le JSON ne constitue pas une preuve de jouabilité. L’importeur Godot demande encore une adaptation ; aucun jeu complet n’est annoncé. Les contrôles géométriques ne prouvent ni qu’un parcours est franchissable, ni l’originalité juridique de tous les contenus générés.

Le mode fake reste une fixture de test explicite, distincte de l’appel réel enregistré. Le parcours retenu utilise un agent ; les autres composants multi-agents du dépôt restent expérimentaux. Une clé fournisseur, un accès réseau et un crédit API sont nécessaires pour reproduire la génération réelle.

Pourquoi Darkwood participe

CONTENT FACTORY

Darkwood relie PHP, outils, agents et automatisation pour rendre l’exécution observable et reproductible. Le hackathon permet de confronter ce travail aux préversions Symfony AI et MCP et de documenter leurs limites à partir d’un cas réel.

Le site officiel du hackathon, consulté le 18 novembre 2026, demande un dépôt public exécutable et une vidéo réelle de 90 secondes, à remettre avant le 22 novembre à 18 h CET. La décision d’acceptation appartient aux organisateurs.
