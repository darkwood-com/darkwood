# Contributing to Darkwood

Darkwood is maintained by Mathieu Ledru and developed in this canonical
monorepo by authorized members of the Darkwood GitHub organization.

## Issues

Public issues are welcome for bug reports, suggestions, and feature requests.
Do not include credentials, private data, or security-sensitive details in a
public issue.

## Code changes

Code pull requests are reserved for authorized Darkwood organization members.
External contributors should open an issue instead of a pull request. GitHub
may technically allow a pull request from a public fork; such a pull request is
not an accepted contribution channel and will be redirected to an issue.

Generated satellite repositories are publication destinations. Code changes
must be made in this canonical monorepo.
