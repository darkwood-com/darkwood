# Darkwood

Public monorepo for Darkwood open-source projects.

## Projects

- [Darkwood GitHub Profile](library/.github) — organization profile and public community templates.
- [Composio MCP](library/composio-mcp) — Symfony MCP server integrating Composio actions and workflows.
- [Connect Flow](library/content-connect-flow) — Symfony prototype connecting natural-language capabilities to the Flow runtime.
- [Crypto Trade](library/content-crypto-trade) — experimental cryptocurrency market-analysis application.
- [Darkwood PHP](library/darkwood-php) — PHP libraries and Symfony bundles.
- [Darkwood Publish Article MCP Apps](library/darkwood-publish-article-mcp-apps) — MCP application for article generation and publication workflows.
- [Darkwood Showreel](library/content-darkwood-showreel) — web and terminal showreel content built with Symfony TUI.
- [Darkwood Memory](library/content-darkwood-memory) — interactive editorial demonstrations about preserving creative memory.
- [Darkwood.com](library/darkwood-portal) — public website and application source.
- [Diablo PHP](library/diablo-php) — archived PHP and FFI game-engine implementation.
- [Flow Partial Function Application](library/content-flow-partial-function-application) — PHP 8.6 and Darkwood Flow study.
- [Flow Pipe](library/content-flow-pipe) — streaming token-pipeline demonstration.
- [Flow This Person Does Not Exist](library/content-flow-thispersondoesnotexist) — parallel fictional-person image fetcher.
- [Flow JEV](library/content-flow-jev) — archived experimental Flow and JEV platform integration.
- [Flow Live](library/content-flow-live) — live Darkwood Flow demonstration application.
- [Hearthbreaker](library/content-hearthbreaker) — archived Hearthstone helper preserved as a sanitized source snapshot.
- [Hellcats Over the Pacific](library/hellcats-over-the-pacific) — evidence-backed Godot port of the classic Macintosh flight simulator.
- [Kibono Flow](library/content-kibono-flow) — observable product-sync and ETL demonstration.
- [LGS](library/lgs) — the LGS game and its Godot implementation.
- [LLM Game of Life](library/content-llm-game-of-life) — pedagogical exploration of LLM concepts in PHP.
- [Mario Orchestration](library/content-mario-orquestration) — Symfony AI and Godot multi-agent demonstration.
- [matyo91](library/matyo91) — GitHub profile assets and automation.
- [matyo91 Live](library/content-matyo91-live) — streaming scenes, overlays and editable media sources.
- [Nolife Language](library/content-nolife-language) — LLM token-cost experiment across languages.
- [Nolife Local](library/content-nolife-local) — archived local AI and 3D experimentation application.
- [Nolife Models](library/nolife-models) — local AI model catalog and runtime explorer.
- [Nolife Tokens](library/content-nolife-tokens) — token-analysis and Flow pipeline experiments.
- [Nolife Tracker](library/nolife-tracker) — terminal registry for AI accounts and subscriptions.
- [Omer Quotes](library/content-omer-quotes) — archived quotation extraction and exploration project.
- [PHP Flow](library/content-php-flow) — PHP profiling demonstration using Darkwood Flow.
- [Prime AI Answer](library/prime-ai-answer) — MCP experiment for concise AI-assisted answers.
- [Quake III Arena PHP](library/quake-3-arena-php) — archived PHP FFI engine study.
- [Recherche Entreprise MCP](library/recherche-entreprise-mcp) — PHP MCP and company-research experiment.
- [RxJS Flow](library/rxjs-flow) — RxJS streaming concepts mapped onto Darkwood Flow.
- [SketchUp Shape](library/content-sketchup-shape) — archived shape-generation experiment.
- [Slides](library/slides) — presentation authoring and controlled publication platform.
- [Thumbnail MCP](library/thumbnail-mcp) — Replicate-backed thumbnail generation tool.
- [URL Scraping API](library/url-scrapping-api) — Symfony API for structured web extraction.
- [Uniflow](library/uniflow) — workflow and commerce platform.
- [VibePHP Flow](library/content-vibephp-flow) — VibePHP profiling demonstration using Darkwood Flow.
- [WYSIWYL](library/content-wysiwyl) — What You See Is What You Learn experiment.

Projects live under [`library/`](library/). Public discovery metadata is available
in [`tags.json`](tags.json). See [`CONTRIBUTING.md`](CONTRIBUTING.md) for the
public issue and code contribution policy. Card status, dependencies and
sparse load/unload commands are documented in [`CARDS.md`](CARDS.md).
